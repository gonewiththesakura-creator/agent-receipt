# 定价表说明（references/pricing.md）

> 按需加载：只有当 skill 需要说明“金额是怎么算出来的”、
> 或用户问“这个价格准不准”时，才读本文件。

## 口径

- 金额来自 `src/pricing/prices.ts` 的版本化标价表（当前版本见收据
  上的 `priceTableVersion`，2026-11-19 对厂商定价页核实过），按“公开标价”
  折算，不是发票。覆盖 Claude 5 系列、Fable、Mythos 与 GPT-6 变体；
  那次核实修掉了 Opus 4.5–4.8 被高估 3 倍的错误。
- 报金额时必须同时说：**按公开标价估算，不是你的发票**。厂商
  控制台才是权威账单。
- 标价会变：厂商改价、改模型 id、改缓存 TTL，收据都可能变。
  不要把标价表里的数字当作永久事实引用。

## 表里没有的模型

- `priceFor()` 查不到的模型，收据只报 token 数，不猜价格；
  `costUsd` 会变成 `null`，`unknownPriceModels` 会列出这些模型。
  其中 Claude Haiku 5.5 是**有意不标价**的：它的价格按提示词长度
  分档（10 万 token 上下两档），收据无法按请求归属提示词长度，
  所以不猜、只报 token 数——不要自己按任一档估算。
- 遇到这种情况，告诉用户“这几个模型不在标价表里，只有 token 数”，
  不要自己按相近模型的价格估算。

## 订阅与 API 的区别

- API 计费：有美元账单，美元上限（`run --cap`）只对它有效。
- 订阅计费：没有美元账单，只讲 token 数与 5 小时窗口占比，
  不要把 token 数折算成美元。
- 两者不要混着算、混着讲。
