# 变现模式（docs/monetization.md）

> 本文件只写方向，不承诺、不收费。v0.1 及核心功能永远开源免费。
> 现在没有任何付费墙、没有任何遥测、不会向你要钱。

## 原则

- **核心永远免费。** 收据（daily / monthly / session / receipt）、
  resume 预测、模型切换报告、`run --cap` 硬上限、Claude Code
  skill ——这些 v0.1 已有的功能，以及它们的后续改进，永远在
  MIT 许可证下开源免费，不会移到付费版。
- **现在不收任何费用。** 没有订阅、没有按量计费、没有“Pro 版”。
  README 顶部的赞助区目前是空位，只接受自愿赞助。
- **没有遥测。** 工具不联网、不上传日志、不统计使用情况。
  未来任何遥测（如果有）都必须是明确 opt-in，默认关闭。
  现在没有，将来也不会悄悄加上。

## Open-core 分层（方向，未承诺时间表）

照着 Univer 的 open-core 模式，未来可能的商业层只列方向：

| 层 | 内容 | 状态 |
|---|---|---|
| 开源核心（免费，MIT） | 本地收据、resume 预测、模型切换报告、硬上限、skill、定价表 | 已有，永远免费 |
| 团队汇总版（可能商业） | 多人收据汇总、团队周报、共享定价表 | 方向，未开始 |
| 定价自动更新（可能商业） | 标价表自动跟随厂商改价、变更提醒 | 方向，未开始 |
| 托管收据服务（可能商业） | 团队共用的收据看板、历史趋势、导出 | 方向，未开始 |
| 咨询与部署支持（可能收费） | 帮团队部署、接自家 agent、定制收据格式 | 接受咨询，见 README“支持与咨询” |

以上商业层目前**一行代码都没有**，也没有任何排期。列出来只是
为了让“口子”先留好：核心与商业层的边界现在就划清，免得将来
把开源功能往付费版里挪。

## 赞助与咨询（现在就能做的事，照着 daily_stock_analysis）

- **赞助**：自愿赞助，README 顶部留了赞助区。赞助不解锁任何
  功能（因为没有付费功能），只是支持维护。
- **咨询**：部署支持（帮团队把收据接进自己的 agent 工作流）、
  功能扩展（按团队需求定制收据格式与报告）。联系方式走
  GitHub Issues / Discussions，不用邮件。
- **赞助商位**：README 顶部的赞助区以后可以放赞助商链接，
  前提是赞助商与本项目方向相关（AI 编码、开发者工具），
  且明确标注为赞助。现在没有任何赞助商，不要编造。

## 不做的事

- 不把已开源的功能改成付费。
- 不加 license 检查、不加收费墙、不加使用次数限制。
- 不卖用户数据（工具本来也不收集数据）。
- 不在收据里插广告。
